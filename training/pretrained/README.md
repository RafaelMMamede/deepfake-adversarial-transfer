# Backbone initialization weights

The detector configurations in `training/config/detector/` preserve the
initialization used by the released experiments. Large initialization weights
are not committed to this Git repository.

## ImageNet initialization

Place the following upstream checkpoints at the exact paths expected by the
corresponding detector YAML files.

| Backbone | Expected local file | Upstream source |
| --- | --- | --- |
| Xception | `training/pretrained/xception-b5690688.pth` | http://data.lip6.fr/cadene/pretrainedmodels/xception-b5690688.pth |
| ResNet-34 | `training/pretrained/resnet34-b627a593.pth` | https://download.pytorch.org/models/resnet34-b627a593.pth |
| EfficientNet-B4 | `training/pretrained/efficientnet-b4-6ed6700e.pth` | https://github.com/lukemelas/EfficientNet-PyTorch/releases/download/1.0/efficientnet-b4-6ed6700e.pth |
| DeiT-S | `training/pretrained/deit_small_patch16_224-cd65a155.pth` | https://dl.fbaipublicfiles.com/deit/deit_small_patch16_224-cd65a155.pth |
| Swin-T | `training/pretrained/swin_tiny_patch4_window7_224.pth` | https://github.com/SwinTransformer/storage/releases/download/v1.0.0/swin_tiny_patch4_window7_224.pth |
| ViT-B/16 | no local checkpoint required | loaded by `timm` because `training/config/detector/vitb16.yaml` sets `pretrained: true` and `checkpoint_path: null` |

These links point to the upstream model sources used by the corresponding
implementations. The Xception checkpoint is the Cadene
`pretrainedmodels` ImageNet weight referenced by DeepfakeBench-style Xception
implementations.

The project does not redistribute these ImageNet initialization files. Their
upstream licenses and terms remain applicable.

## Face-recognition initialization

The `*_fr_pretrain.yaml` detector configurations do not use the ImageNet
checkpoints above. They expect backbone-only checkpoints generated by the
face-recognition pretraining workflow in `pretraining/`.

The workflow is:

1. Obtain BUPT-BalancedFace and RFW under their respective access terms.
2. Train the selected backbone using the matching configuration in
   `pretraining/configs/`.
3. Export the trained backbone into the detector-compatible format:

```bash
python training/pretrained/export_fr_backbone.py \
  --root training/pretrained \
  --dry-run
```

After checking the discovered runs, omit `--dry-run` to write the converted
backbone file:

```bash
python training/pretrained/export_fr_backbone.py \
  --root training/pretrained
```

The exported filename is `backbone_only_compatible.pth`. Each
`*_fr_pretrain.yaml` file records the exact relative directory expected for
the corresponding architecture.

## Final detector checkpoints

The 60 final trained detector checkpoints are released separately at:

https://huggingface.co/poisonedchicken/deepfake-adversarial-transfer-models

Those final checkpoints are distinct from the initialization weights described
on this page.

## Git hygiene

`*.pth`, `*.pt`, `*.ckpt`, `saved_models/`, and
`saved_models_fr_pretrain/` are ignored by the repository. Keep downloaded
initialization weights and locally trained checkpoints out of Git.
